# 🛍️ Customer Behavior Data Analysis

This project is an end-to-end Data Analytics portfolio project that analyzes retail customer shopping behavior using **Python, PostgreSQL, and Power BI**. The objective is to transform raw customer transaction data into meaningful business insights through data cleaning, exploratory analysis, SQL querying, and interactive dashboard creation.

---

## 📌 Project Overview

The project demonstrates the complete data analytics workflow, including:

- Data cleaning and preprocessing using Python
- Exploratory Data Analysis (EDA)
- Loading cleaned data into PostgreSQL
- Writing SQL queries to answer business questions
- Creating interactive Power BI dashboards
- Extracting actionable business insights from customer purchasing behavior

## 🚀 How to Run the Project

### Clone the repository

```bash
git clone https://github.com/Prisha14jaiswal/Customer_Behaviour_Data_Analysis.git
```

### Navigate to the project

```bash
cd Customer_Behaviour_Data_Analysis
```

### Install required libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2
```

### Open the Jupyter Notebook

```bash
jupyter notebook Customer_Shopping.ipynb
```

### Load the cleaned data into PostgreSQL

- Create a PostgreSQL database.
- Execute the Python notebook to import data.
- Run the SQL queries.

### Open Power BI Dashboard

Open the `.pbix` file in Power BI Desktop to explore the dashboard.
